# Frontend Application

Frontend application for Pepsi and Coke project, built with Node.js.

## Getting Started

**Prerequisites:** Node.js

```bash
# 1. Navigate to frontend directory
cd frontend

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev
```

## Scripts

| Command       | Description                        |
| ------------- | ---------------------------------- |
| `npm run dev` | Run the application in dev mode    |
| `npm start`   | Start the production build/server  |
| `npm run test`| Run tests                          |
