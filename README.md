# 2110503_Project_pepsi-and-coke

Project for 2110503 Software Development Practice from group Pepsi and Coke.

This monorepo contains both the **Backend** (Node.js/Express/MongoDB) and **Frontend** (Node.js) applications.

## Repository Structure

```
├── .github/workflows/   # CI/CD workflows
├── backend/             # Node.js REST API service
├── docs/                # System architecture & UML diagrams
└── frontend/            # Node.js Frontend application
```
